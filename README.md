# Room Scent · Shop + POS

รวมสองโปรเจกต์ไว้ในระบบเดียว (Next.js + Supabase):

- **room** (สอนใช้ AI 101 Ep.7) → หน้าร้านออนไลน์ `/` เลือกสินค้าตามมู้ด ใส่ตะกร้า สั่งซื้อ `/checkout`
- **mini-pos** (Ep.8 + Ep.9 แจ้งเตือน เปลี่ยนจาก Telegram เป็น LINE) → หลังร้าน `/admin`
  - `/admin` ภาพรวมยอดขายวันนี้ · `/admin/pos` ขายหน้าร้าน · `/admin/orders` ออเดอร์ออนไลน์
  - `/admin/products` จัดการสินค้า/สต็อก (ตั้งได้ว่าสินค้าไหนโชว์หน้าร้าน) · `/admin/history` ประวัติการขาย

สต็อกเป็นชุดเดียวกัน: ขายหน้าร้านหรือมีคนสั่งออนไลน์ สต็อกลดทันที ยกเลิกออเดอร์แล้วคืนสต็อกให้อัตโนมัติ

## ติดตั้ง
1. Supabase → SQL Editor → รันไฟล์ `supabase/schema.sql` ทั้งไฟล์ (รันซ้ำได้ ใช้กับโปรเจกต์ mini-pos เดิมได้เลย)
2. Supabase → Authentication → Users → **Add user** สร้างบัญชีพนักงาน (ติ๊ก Auto Confirm User) และปิด "Allow new users to sign up"
3. Supabase → Authentication → URL Configuration → เพิ่ม `https://<โดเมน>/set-password` ใน Redirect URLs (สำหรับลืมรหัสผ่าน)
4. คัดลอก `.env.example` เป็น `.env.local` แล้วใส่ค่า (บน Vercel ให้ตั้งใน Settings → Environment Variables)
5. `npm install` แล้ว `npm run dev`

## สิ่งที่เปลี่ยนจากโปรเจกต์เดิม
- ออเดอร์ออนไลน์เก็บใน Supabase แทน Google Sheet / Apps Script และราคาคำนวณจากฐานข้อมูล (เดิมราคาส่งมาทาง URL แก้เองได้)
- หลังร้านต้องล็อกอิน (เดิม mini-pos ใครเปิดลิงก์ก็แก้ราคา/ลบสินค้าได้)
- ขาย/ตัดสต็อกทำในทรานแซกชันเดียวในฐานข้อมูล กันขายเกินสต็อกเมื่อขายพร้อมกันหลายเครื่อง
- แจ้งเตือน LINE ส่งจากเซิร์ฟเวอร์เท่านั้น รวมเป็นข้อความเดียวต่อบิล (เดิม `/api/line` เปิดให้ใครก็ยิงได้ และบิลที่มีหลายรายการเกินลิมิต 5 ข้อความของ LINE)
- ลบสินค้าที่เคยขายแล้วได้ ประวัติการขายยังอยู่
- รูปภาพย่อขนาดจาก ~3 MB เหลือ ~200 KB · รูปเทียนหอมและรูปห้องสร้างด้วย Figma AI
